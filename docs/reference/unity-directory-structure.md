# Reference: Unity Project Directory Structure

This reference document describes the default folders generated by the Unity Engine upon project creation, alongside the recommended organizational structure inside the `Assets/` directory.

---

## 1. Engine-Generated Root Folders
When Unity creates a new project, it generates the following directories at the root of your project:

| Folder Name | Owner | Git Status | Description |
| :--- | :--- | :--- | :--- |
| **`Assets/`** | **User** | **Tracked** | The primary folder containing all source files for your game (scripts, 3D models, textures, scenes). |
| **`Packages/`** | **User/Unity** | **Tracked** | Contains `manifest.json` which tracks active package versions (e.g., Shader Graph, input systems). |
| **`ProjectSettings/`** | **Unity** | **Tracked** | Stores global project settings, physics configs, tag definitions, and target platform builds. |
| **`Library/`** | **Unity** | *Ignored* | The local database cache where Unity stores processed assets. Safely deleted; Unity will rebuild it on start. |
| **`Logs/`** | **Unity** | *Ignored* | Contains output log files and compilation details from recent editor sessions. |
| **`Temp/`** | **Unity** | *Ignored* | Temporary directories used by the editor during compilation or project loading. |
| **`UserSettings/`** | **Unity** | *Ignored* | Personal preferences, window layout configurations, and editor status metrics. |

---

## 2. User-Created Sub-Directories (`Assets/`)
To maintain project cleanlines, all custom scripts, models, and UI files should be organized within standard folders inside the `/Assets` directory:

```text
Assets/
├── Animations/       # Keyframed animations and Animation Controllers.
├── Audio/            # SFX, background music tracks, and Audio Mixers.
├── Editor/           # C# scripts containing custom Unity Editor extensions (compiled separately).
├── Materials/        # Render materials defining surface color, shininess, and mapping properties.
├── Models/           # 3D meshes (e.g., .fbx, .obj) imported from Blender.
├── Physics/          # Custom Physics Materials defining friction and bounciness.
├── Prefabs/          # Reusable GameObjects saved with preset configurations and scripts.
├── Scenes/           # Individual levels, main menu setups, and UI views (.unity files).
├── Scripts/          # C# source files controlling logic, divided by subsystem.
│   ├── Controllers/  # Input and camera control scripts.
│   ├── Simulation/   # Background physics and orbital calculation logic.
│   └── UI/           # User interface dynamic logic.
├── Textures/         # 2D image assets, UI sprites, and elevation/radiation data maps.
└── ThirdParty/       # Place downloaded Asset Store packages here to avoid root pollution.
```
