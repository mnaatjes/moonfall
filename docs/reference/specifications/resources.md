# Specifications: Lunar Resources

This document outlines the resources present on the lunar surface, their detection profiles, and their game utility.

---

## Lunar Resources Database

| Resource ID | Resource Name | Base Overlay Channel | Primary Mining Node | Extraction Difficulty | Key Game Utility |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `water_ice` | Water Ice | Green (Overlay Map) | Polar Shadowed Craters | High (requires heating/extraction) | Life support, liquid hydrogen rocket fuel synthesis. |
| `titanium` | Titanium (Ilmenite) | UV-Visible (TiO2 ratio) | Mare Basalt Plains | Medium (requires smelting) | Structural components, base hull panels, electronics. |
| `helium_3` | Helium-3 | Solar Wind Deposition | Regolith Surface Sheets | Very High (requires massive heating) | Late-game clean fusion reactor fuel source. |
| `silicon` | Silicon | Regolith / Silicates | Global Highlands / Plains | Low | Solar panel manufacturing, semiconductors. |
