# Instructions: Game Design Document (GDD)

Use this document to establish the high-level design framework, objectives, and progression. It should cover:

1.  **Core Game Objective:**
    *   *Example:* Safely deploy the hopping drone swarm by 2028 and claim sector grids before rivals arrive.
2.  **Win / Loss Conditions:**
    *   *Win:* Successfully establish launch infrastructure and deploy the swarm.
    *   *Loss:* Structural grid collapses due to unchecked radiation storms, or running out of funds/resources.
3.  **Core Mechanics and Constraints:**
    *   *Resource Management:* Power, water ice, titanium.
    *   *Environmental Hazards:* Radiation levels limiting astronaut/electronics operation times.
4.  **Progression Stages:**
    *   *Stage 1: Orbit Operations* (Scanning and probe launches).
    *   *Stage 2: Surface Landing* (Establishing the initial landing pad and basic life support/power).
    *   *Stage 3: Swarm Infrastructure* (Manufacturing and launching propulsive hopping drones).
