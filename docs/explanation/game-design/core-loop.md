# Instructions: Core Gameplay Loop

Use this document to design and detail the player's core gameplay loop. It should cover:

1.  **The Second-to-Second Loop (Active Gameplay):**
    *   *Example:* Controlling camera, checking resource levels, issuing movement commands to rovers/drones.
2.  **The Minute-to-Minute Loop (Tactical Planning):**
    *   *Example:* Selecting construction sites, building solar grids, routing power lines, setting up mining extractors.
3.  **The Hour-to-Hour Loop (Strategic Goals):**
    *   *Example:* Completing drone deployment phases, launching probes to scan new sectors, upgrading mission control facilities.
